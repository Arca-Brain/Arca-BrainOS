# 🎨 Arca-BrainOS Visual Assets

This directory contains the official branding and visual assets for the Arca-BrainOS GitHub repository and documentation.

## 📁 Files & Specifications

| Asset File | Format & Ratio | Resolution / Role | Primary Usage |
| :--- | :--- | :--- | :--- |
| `arcabrain_banner.jpg` | JPEG (16:9) | Panoramic Widescreen | Header banner for `README.md`, `README.fr.md`, `MANIFESTO.md`, and `MANIFESTO.fr.md`. |
| `arcabrain_github_icon.jpg` | JPEG (1:1) | High-Contrast Square | GitHub Organization / Repository avatar, social cards, and favicon. |
