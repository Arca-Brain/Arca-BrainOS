# 🛠️ Skills Catalogue (Arca-BrainOS Agentic Skills)

> *This directory contains all agentic skills executable by Antigravity and declared in [[AGENTS.md]].*

---

### 📥 Inbox Cluster & Triage
- [[Skill_arca-inbox-process]] : *Automatic triage, YAML cleaning, and routing of raw notes in `0-Inbox/`.*
- [[Skill_arca-organize-idea]] : *Qualification and structuring of raw idea notes while preserving original text.*
- [[Skill_arca-create-note]] : *Fast instantiation of Projects (`P-`), Themes (`T-`), or Areas (`Area`) via direct aliases.*

### 🧪 Distillation & Media Cluster
- [[Skill_arca-distill]] : *Master orchestration skill for raw source ingestion (synthesis, anchoring, archiving, impact).*
- [[Skill_arca-synthesize]] : *Drafting structured conceptual synthesis notes `AI-Distil-[Name]`.*
- [[Skill_arca-converge]] : *Structural integration into Theme MOCs (`T-`), wikilink activation, and index updates.*
- [[Skill_arca-impact]] : *Interactive impact analysis proposing concrete tasks for projects `P-` and lessons `L-`.*
- [[Skill_arca-youtube]] : *YouTube transcript extraction and raw note creation in `0-Inbox/Youtube/`.*

### 🔍 Exploration & Maintenance Cluster
- [[Skill_arca-query]] : *Cognitive bridge and on-demand semantic search crossing distilled sources and Inbox.*
- [[Skill_arca-audit]] : *Vault health diagnostic (PARA ratio, orphans, ghost links) and project ROI consolidation.*
- [[Skill_arca-test-suite]] : *Agentic test bench and automated non-regression test suite on fixtures.*

### 🪵 Deep Work & Execution Cluster
- [[Skill_arca-resume]] : *Start and cognitive framing before a Deep Work run with log initialization.*
- [[Skill_arca-close-session]] : *Session closure, AI ROI calculation, task updates, and project session worklog.*
