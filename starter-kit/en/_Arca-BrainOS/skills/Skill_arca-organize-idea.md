# 🛠️ Skill : arca-organize-idea (Idea Structuring & Category Typing)

- **Reference Process:** [[Process-Inbox-Clean-and-Dispatch]]

## Trigger
Execute when user enters `arca-organize-idea` (or `organize-idea`).

## Objective
Structure raw notes from Inbox while preserving 100% of original raw text under `## 📝 Raw Note`. Formulate key idea, generate actions, and link to projects or themes.

## Sequential Execution Workflow
1. **Target Note or Batch Scan:** Target specified file or scan `0-Inbox/`.
2. **Category & Target Diagnostic:** Classify as `idea`, `action`, `project-seed`, or `source`.
3. **Interactive Validation:** Present diagnostic in chat before writing.
4. **Execution:** Apply `Template-Idea.md`, fill YAML, preserve raw note, and link synamtically.
5. **Log:** Record action in `_Arca-BrainOS/log.md`.
