# 🛠️ Skill : arca-query (Cognitive Bridge & Knowledge Query)

- **Reference Process:** [[Process-Semantic-Exploration-and-Research]]

## Trigger
Execute when user enters `arca-query` followed by a question or topic.

## Objective
Act as a cognitive bridge crossing distilled knowledge, raw Inbox sources, and identifying knowledge gaps without modifying vault files (100% conversational).

## Sequential Execution Workflow
1. **Multi-level Search:** Semantic search across `2-Ressources/IA-generated/`, `0-Inbox/`, and Theme MOCs.
2. **Structure & Gap Analysis:** Identify unlinked related notes and missing connections.
3. **Response Formatting:** Deliver Flash Report in chat with Distilled Knowledge (`[[AI-Distil-Name]]`), Raw Inbox Sources, and Semantic Gaps.
4. **Optional Saving:** Offer to save high-value synthesis into `AI-Query-[Name].md` upon user request.
