# 📋 Templates Catalogue (Arca-BrainOS Obsidian Templates)

> *This directory contains all standardized note templates for the Second Brain.*

### 🏗️ Structural Templates
- [[Template-Project]] : *Master template for project notes (`P-`), including session metadata, milestones, and worklog.*
- [[Template-Area]] : *Template for Life Areas (`3-Domaines-de-vie/`), including scope, seasonal agenda, and Dataview queries.*
- [[Template-Theme]] : *Template for Theme MOC cards (`T-`), including vision, syntheses, and graph connections.*
- [[Template-Process]] : *Template for macro-process guides (inputs, steps, Human/AI matrix, outputs).*
- [[Template-Idea]] : *Template for raw idea qualification (Raw Note, summary, actions, and connections).*

### 📓 Journal Templates
- [[Template-Daily]] : *Template for daily notes (worklog, quick captures, and review).*
